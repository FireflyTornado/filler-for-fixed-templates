# 模板填充工具（Template Filler Tool）

> **语言切换：[English](README.en.md)**

一个基于 Java Swing 的桌面工具：使用统一变量系统填充文本或 Word 模板，并支持预览、复制和安全导出结果。

## 功能特性

- **左右分栏界面** → 左侧集中显示模板编辑与生成结果，右侧集中显示日期和统一变量输入；两组分隔条均可拖动并自动记忆位置
- **统一变量输入** → `{{变量名}}` 是推荐格式，每个变量可选择“数值 / 短字符串 / 多行文本”；数值留空按 0
- **兼容旧字符串语法** → `[[字符串]]` 无需修改即可继续使用，首次加载默认按多行文本处理
- **紧凑多行编辑** → 多行变量在主界面显示单行预览，通过“展开…”弹窗编辑完整内容
- **类型草稿保护** → 数值、短字符串和多行文本分别保存自己的草稿，切换类型或取消有损转换不会丢失原内容
- **表达式数值锁定** → 以 `=` 开头表示算术表达式，如 `{{=变量1/变量2}}`；表达式引用的变量自动锁定为数值，支持 `+ - * / **` 和括号，结果保留两位小数
- **日历基准日期** → 所有内置日期变量均以日历选中的日期为基准；每次启动默认同步系统当天日期，也可手动输入 `yyyy-MM-dd` 或打开弹出日历选择日期
- **完整日期推导** → 支持昨日/今日/明日、上月/本月/下月、上年/本年/下年及本月月首/月末，跨月、跨年和闰年均自动处理
- **独立配置记忆** → 应用状态保存到 `config.json`，每个模板的变量值和类型分别保存到 `Config/模板名.json`
- **旧配置安全迁移** → 首次升级时只读迁移 `last_values.json`，迁移后不再修改或删除旧文件；配置采用临时文件与原子替换写入
- **结果状态保护** → 修改模板、变量类型、变量值或日期后立即废弃旧结果，禁止误复制或误保存
- **错误定位与可访问性** → 数值和日期错误实时显示文字/符号反馈，可用“定位错误”或 `F4` 循环聚焦；支持 `F1` 帮助、`Ctrl+Enter` 生成和 `Ctrl+S` 保存模板
- **非模态帮助窗口** → 提供语法说明、全部日期变量和随模板实时刷新的当前变量清单，打开后仍可继续操作主界面
- **多模板管理** → 模板文件任意命名存放在 `Templates/` 文件夹内，可「选择模板文件…」切换、「新建模板」、修改后「保存模板」写回对应文件，并记住上次使用的模板，下次启动自动恢复
- **模板即时修改** → 可在界面中直接编辑并保存，或点「打开文件夹」用外部编辑器修改
- **Word 模板支持** → 可直接选择 `.docx` 文件作为模板，正文、表格、页眉/页脚、脚注/尾注、批注、文本框中的 `{{变量名}}` 与 `[[字符串]]` 都会被替换，且保留原有文字格式（字体、加粗、字号、颜色）与段落格式（对齐、缩进、行距）；生成的 Word 结果通过「保存结果到文件」导出

## 快速开始

**环境要求**：Windows + JDK 17 或更高版本。

**运行**：

1. 双击 `launcher.bat`
2. 命令行执行 `java -jar TemplateTool.jar`

**修改模板**：模板是 `Templates/` 文件夹内的纯文本文件。点击顶栏「选择模板文件…」选择要用的模板，在下方编辑区修改后点「保存模板」写回该文件；「新建模板」可创建新文件；「打开文件夹」可打开模板文件夹，直接管理模板文件。

**填写变量**：右侧每个变量只显示一次。普通变量可选择数值、短字符串或多行文本；表达式引用的变量固定为数值。多行文本通过“展开…”编辑，取消不会修改原内容。

**键盘操作**：`Ctrl+Enter` 生成结果，`Ctrl+S` 保存文本模板，`F1` 打开帮助，`F4` 循环定位输入错误；辅助对话框可用 `Esc` 关闭。

**使用 Word 模板**：在 Word 中把需要填写的部分写成推荐的 `{{变量名}}`，旧模板中的 `[[字符串]]` 仍受支持。打开 `.docx` 后模板内容保持只读，“保存模板”禁用但仍可新建 `.txt` 模板；生成后的 Word 结果通过“保存结果到文件”导出。

## 语法

| 写法 | 说明 | 示例 |
| --- | --- | --- |
| `{{变量名}}` | 推荐格式；可选择数值、短字符串或多行文本 | `{{天气}}` |
| `{{=变量1*变量2}}` | 算术表达式；引用变量自动锁定为数值，结果保留 2 位小数 | `{{=本月累计/本月计划}}` |
| `{{今日年}} {{今日年月}} {{今日年月日}}` | 日历基准日期 | `{{今日年月日}}` |
| `{{昨日年}} {{昨日年月}} {{昨日年月日}}` | 基准日期的前一天 | `{{昨日年月日}}` |
| `{{明日年}} {{明日年月}} {{明日年月日}}` | 基准日期的后一天 | `{{明日年月日}}` |
| `{{本月年}} {{本月年月}}` | 基准日期所在年份或年月 | `{{本月年月}}` |
| `{{上月年}} {{上月年月}}` | 基准日期上一个月所在年份或年月 | `{{上月年月}}` |
| `{{下月年}} {{下月年月}}` | 基准日期下一个月所在年份或年月 | `{{下月年月}}` |
| `{{上年}} {{本年}} {{下年}}` | 基准日期的前一年、所在年或后一年 | `{{本年}}` |
| `{{本月月首}} {{本月月末}}` | 基准日期所在月的第一天或最后一天 | `{{本月月末}}` |
| `[[字符串名]]` | 旧模板兼容格式；默认多行文本，不会自动改写 | `[[备注]]` |

## 构建

双击 `build.bat`，或在命令行执行：

```bat
build.bat
```

构建需要 JDK（含 `javac` 和 `jar`）；构建脚本会先运行回归测试，成功后生成 `TemplateTool.jar`。

## 目录结构

```
├── build.bat               # 编译源码并打包 TemplateTool.jar（自动查找 JDK）
├── launcher.bat            # 一键运行（自动查找 java）
├── Templates/              # 模板文件存放目录（任意命名；首次运行自动生成 example.txt 与 example.docx）
├── config.json             # 上次模板与分隔条位置等应用级配置
├── Config/                 # 每个模板独立的变量值与类型配置
├── last_values.json        # 旧版数据，仅首次迁移时只读，迁移后不再修改
├── src/main/java/com/firefly/
    ├── Main.java                 # 程序入口：设置高 DPI / 系统外观，启动主窗口
    ├── TemplateToolApp.java      # 主窗口：界面布局、事件处理、日历基准日期与数据同步
    ├── TemplateConstants.java    # 全局常量：日期变量及推导、占位符/正则、文件名、默认示例模板
    ├── core/                     # 逻辑层：模板读写、解析、渲染、求值等
    │   ├── TemplateStore.java       # Templates 文件夹读写（列举/读取/写入/首次生成 example.txt 与 example.docx）
    │   ├── ExpressionEvaluator.java # 安全算术表达式求值（+ - * / ** 与括号，自写递归下降解析）
    │   ├── AppConfigStore.java      # config.json 应用级配置（容错读取、原子写入）
    │   ├── TemplateConfigStore.java # Config/ 下每模板独立变量配置
    │   ├── VariableType.java         # 数值 / 短字符串 / 多行文本类型
    │   ├── VariableInputState.java   # 统一变量值、类型与表达式锁定状态
    │   ├── LegacyConfigMigrator.java # 旧 last_values.json 一次性只读迁移
    │   ├── LastValuesStore.java     # 旧 last_values.json 的只读迁移支持
    │   ├── MiniJson.java            # JSON 读写
    │   ├── DocxProcessor.java       # Word（.docx）模板：文本提取 + 占位符替换 + 内置 example.docx 生成（零依赖，保留 run/段落格式）
    │   ├── TemplateParser.java      # 模板占位符解析：提取变量 / 自动日期 / 字符串变量
    │   ├── TemplateRenderer.java    # 把模板渲染成最终结果（替换、求值、原样输出字符串；纯文本与 Word 共用 resolve）
    │   ├── TextFileWriter.java      # 文本文件读写（UTF-8 带 BOM、换行转 CRLF，兼容记事本）
    │   └── ValueNormalizer.java     # 数字输入校验/规范化（留空按 0，非数字返回 null）
    └── ui/                     # Swing 界面组件
        ├── DatePickerPanel.java      # 日期基准输入与弹出日历（启动时同步系统日期）
        ├── ResultPanel.java          # 「结果输出」区（只读多行文本）
        ├── ScrollablePanel.java      # 可滚动纵向表单面板（宽度自适应、高度随内容）
        ├── VariableInputPanel.java  # 三种变量类型共用的紧凑输入面板
        ├── MultilineEditorDialog.java # 模态多行文本编辑弹窗
        ├── VariableTypeConversionDialog.java # 有损类型转换确认
        ├── ValidationIssueManager.java # 实时错误集合与循环定位
        └── TemplateHelpDialog.java  # 非模态语法、日期与当前变量帮助
└── src/test/java/com/firefly/
    └── TemplateFeatureTests.java # 统一变量、配置安全与迁移回归测试
```
