# 模板填充工具（Template Filler Tool）

> **语言切换：[English](README.en.md)**

一个基于 Java Swing 的桌面工具：使用统一变量系统填充文本或 Word 模板，并支持预览、复制和安全导出结果。

## 功能特性

- **左右分栏界面** → 左侧集中显示模板编辑与生成结果，右侧集中显示日期和统一变量输入；两组分隔条均可拖动并自动记忆位置
- **统一变量输入** → `{{变量名}}` 是推荐格式，每个变量可选择“数值 / 短字符串 / 多行文本”；数值留空按 0，在变量值输入框按 `Tab` 可直接跳到下一变量值
- **旧语法迁移** → 读取到 `[[变量]]` 时可备份并一键转换为 `{{变量}}`
- **紧凑多行编辑** → 多行变量在主界面显示单行预览，通过“展开…”弹窗编辑完整内容
- **会话草稿保护** → 数值、短字符串和多行文本在当前模板编辑会话内分别保留；切换模板或退出后只长期保存当前类型和值
- **可调界面字号** → 默认“较大”，可选择跟随系统/较大/大/特大；基于 Windows 与 JDK 的 DPI 字体继续缩放，不重复计算显示 DPI
- **统一小数位数** → 在“变量填写”区域使用 `−` / `+` 设置当前模板保留的 0～10 位小数；数值变量和表达式结果使用同一设置，默认保留两位
- **日历基准日期** → 所有内置日期变量均以日历选中的日期为基准；每次启动默认同步系统当天日期，也可手动输入 `yyyy-MM-dd` 或打开弹出日历选择日期
- **完整日期推导** → 支持按日、月、年月、完整日期及年份输出昨日/今日/明日、上月/本月/下月、上年/本年/下年，并支持本月月首/月末；跨月、跨年和闰年均自动处理
- **独立配置记忆** → 应用状态保存到 `config.json`，每个模板的变量值、类型和小数位数分别保存到 `Config/模板名.json`；退出时可确认清理本次运行中已检查模板的未使用变量
- **旧配置安全迁移** → 首次升级时只读迁移 `last_values.json`，迁移后不再修改或删除旧文件；配置采用临时文件与原子替换写入
- **结果状态保护** → 修改模板、变量类型、变量值或日期后立即废弃旧结果，禁止误复制或误保存
- **通用后台文件任务** → 模板初始化、加载、导入、保存、刷新与迁移，以及结果生成和导出均在后台执行；状态栏固定显示任务阶段、进度和始终占位的取消按钮，状态文案按操作统一，不再按 TXT/DOCX 文件类型区分
- **安全的模板加载状态** → 切换或刷新模板时先处理未保存修改，再锁定模板工作区并显示进度；成功后整体切换，失败或取消则恢复原模板
- **错误定位与可访问性** → 数值和日期错误实时显示文字/符号反馈，可用“定位错误”或 `F4` 循环聚焦；支持 `F1` 帮助、`Ctrl+Enter` 生成和 `Ctrl+S` 保存模板
- **非模态帮助窗口** → 提供语法说明、运算说明、全部日期变量和随模板实时刷新的当前变量清单，打开后仍可继续操作主界面
- **多模板管理** → 模板文件任意命名存放在 `Templates/` 文件夹内，可「选择模板文件…」切换、「新建模板」、修改后「保存模板」写回对应文件，并记住上次使用的模板，下次启动自动恢复
- **模板即时修改** → 可在界面中直接编辑并保存，或点「打开文件夹」用外部编辑器修改
- **手动刷新模板** → 外部修改模板文件后可点「刷新模板」立即重新读取；界面存在未保存修改时会先提示，避免误丢内容
- **Word 模板支持** → 可直接选择 `.docx` 文件作为模板，替换正文、表格、页眉/页脚、脚注/尾注、批注和文本框中的变量，并保留原有文字与段落格式

## 快速开始

**环境要求**：Windows + JDK 17 或更高版本。

**运行**：

1. 双击 `launcher.bat`
2. 命令行执行 `java -jar TemplateTool.jar`

**修改模板**：模板统一存放在 `Templates/` 文件夹中，支持 `.txt` 和 `.docx`。`.txt` 模板可在下方编辑区直接修改并保存；`.docx` 模板在界面中只读，需要使用 Word 等外部程序编辑后再刷新或重新打开。「新建模板」仅创建 `.txt` 文件，「打开文件夹」可直接管理所有模板文件。

**填写变量**：右侧每个变量只显示一次。普通变量可选择数值、短字符串或多行文本；表达式引用的变量固定为数值。顶部的 `−` / `+` 可调节当前模板的小数位数。多行文本通过“展开…”编辑，取消不会修改原内容。

**键盘操作**：变量值输入框中按 `Tab` 跳到下一变量值；`Ctrl+Enter` 生成结果，`Ctrl+S` 保存文本模板，`Ctrl+加号/减号` 调整界面字号，`Ctrl+0` 跟随系统，`F1` 打开帮助，`F4` 循环定位输入错误；辅助对话框可用 `Esc` 关闭。

**使用 Word 模板**：在 Word 中把需要填写的部分写成 `{{变量名}}`。打开 `.docx` 后模板内容保持只读，“保存模板”禁用但仍可新建 `.txt` 模板；生成后的 Word 结果通过“保存结果到文件”导出。

### 文件操作与进度

- 初始化、加载、导入、保存、刷新、旧语法转换、结果生成和结果导出均作为后台文件任务执行，耗时操作不会阻塞整个主窗口。
- 状态栏使用“加载模板”“保存模板”“生成结果”等统一操作文案，不再根据 TXT 或 DOCX 分别命名；这些文案集中定义在 `FileOperationText` 中。
- 进度区的位置和大小固定，“取消”按钮始终显示；当前任务不可取消时按钮会自动禁用。
- 加载、刷新或切换模板期间，仅模板相关工作区会被临时禁用；加载失败或取消时仍保留原模板及其输入状态。
- 生成结果期间仍可修改模板、日期和变量，也可使用已有结果。每次生成使用开始时取得的数据快照；如果生成期间输入发生变化，完成状态会明确提示该结果与当前输入不一致。
- 切换、新建或刷新模板等操作如果会影响正在生成的任务，程序会先询问是否取消当前生成，不会直接中断。

## 变量语法

### 普通变量

使用双花括号声明变量：

```text
{{变量名}}
```

变量名是花括号中的完整内容，前后空白会被忽略。因此纯数字也可以作为普通变量名：

```text
客户：{{客户名称}}
第一项：{{1}}
备注：{{备注}}
```

每个普通变量可以在界面中选择以下类型：

- **数值**：接受普通十进制、小数和科学计数法；留空按 `0` 处理；替换时按照当前模板的小数位数四舍五入并补足末尾零。
- **短字符串**：按原内容替换，适合单行文字。
- **多行文本**：保留换行，适合备注或长文本。

同名变量在模板中出现多次时只需填写一次。

### 算术表达式

花括号内容以 `=` 开头时表示算术表达式：

```text
{{=数量*单价}}
```

表达式支持 `+`、`-`、`*`、`/`、`**`（乘方）、`%`（后缀百分号）和括号。`5%` 等于 `0.05`，例如 `{{=金额*5%}}`；结果与普通数值变量统一使用“变量填写”区域设置的小数位数（0～10 位，默认 2 位），并采用四舍五入。表达式引用的变量会自动锁定为数值类型，留空仍按 `0` 处理。帮助窗口的“运算说明”页提供了更多常用写法。

表达式中有两种变量引用方式：

| 写法 | 用途 | 示例 |
| --- | --- | --- |
| 裸变量名 | 名称以文字开头，后面可包含文字、数字或下划线 | `{{=数量*单价}}` |
| `[变量名]` | 纯数字名称、带空格或带特殊字符的名称；也可显式引用普通名称 | `{{=[1]*[2]}}` |

数字变量和数字常量必须明确区分：

```text
{{=1*2}}          数字常量 1 × 2，结果为 2.00
{{=[1]*[2]}}      变量“1” × 变量“2”
{{=数量*2}}       变量“数量” × 数字常量 2
{{=[销售 数量]*[单价-折扣]}}
```

数字常量支持 `5`、`3.5`、`.5`、`2e3`、`1.5E-2` 等形式。内置日期变量不能参与算术运算。

### 内置日期变量

所有日期变量均以界面选择的基准日期为准：

| 写法 | 含义 |
| --- | --- |
| `{{今日年}}` `{{今日年月}}` `{{今日年月日}}` | 基准日期 |
| `{{昨日年}}` `{{昨日年月}}` `{{昨日年月日}}` | 基准日期前一天 |
| `{{明日年}}` `{{明日年月}}` `{{明日年月日}}` | 基准日期后一天 |
| `{{今日}}` `{{昨日}}` `{{明日}}` | 仅输出对应日期的日，如 `1日`、`31日` |
| `{{本月年}}` `{{本月年月}}` | 基准月份 |
| `{{上月年}}` `{{上月年月}}` | 上一个月 |
| `{{下月年}}` `{{下月年月}}` | 下一个月 |
| `{{本月}}` `{{上月}}` `{{下月}}` | 仅输出对应月份，如 `1月`、`12月` |
| `{{本月天数}}` | 基准月份的天数，输出纯数字 `28`、`29`、`30` 或 `31` |
| `{{上年}}` `{{本年}}` `{{下年}}` | 相对基准日期的年份 |
| `{{本月月首}}` `{{本月月末}}` | 基准月份第一天或最后一天，仅输出月日，如 `2月1日`、`2月29日` |

旧版 `[[变量]]` 写法已经弃用。读取旧模板时软件会提供一次性转换，未转换的旧占位符保持原样且不参与填充。

## 构建

双击 `build.bat`，或在命令行执行：

```bat
build.bat
```

构建需要 JDK 17 或更高版本（含 `javac` 和 `jar`）。脚本会清理旧的 `out/` 与 `out-test/`，重新编译源码并运行全部回归测试，测试成功后生成 `TemplateTool.jar`。

## 项目结构

```
├── build.bat                      # 编译、测试并打包 TemplateTool.jar
├── launcher.bat                   # Windows 一键启动脚本
├── .gitignore                     # 忽略构建产物、运行配置和本地编辑器文件
├── TemplateTool.jar               # 构建时由 build.bat 生成的可运行程序
├── out/ / out-test/               # 构建时生成的主程序与测试 class 文件
├── README.md / README.en.md       # 中英文说明文档
├── LICENSE                        # MIT 许可证
├── Templates/                     # 首次运行时自动创建；保存模板及迁移备份
├── Config/                        # 运行时自动创建；保存各模板的变量、类型和小数位数
├── config.json                    # 运行时自动生成；保存界面状态和上次使用的模板
├── last_values.json               # 仅旧版程序生成；新版只读取它进行一次性迁移
├── src/main/java/com/firefly/
│   ├── Main.java                    # 程序入口与系统外观初始化
│   ├── TemplateToolApp.java         # 主窗口、模板加载、生成与迁移交互

│   │   ├── JsonData.java / MiniJson.java # JSON 读写
```

当前工程不依赖 Maven、Gradle 或第三方库：主代码采用 `src/main/java` 布局，回归测试放在项目自定义的 `test/java` 目录并由 `build.bat` 直接编译。`TemplateTool.jar`、`out/`、`out-test/`、`Templates/`、`Config/` 和运行配置均属于生成内容或本机数据，已通过 `.gitignore` 排除。若以后迁移到 Maven 或 Gradle，可再把测试移动到惯用的 `src/test/java`，当前布局无需为现有构建流程调整。
