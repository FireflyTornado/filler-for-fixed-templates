# 模板填充工具（Template Filler Tool）

> **语言切换：[English](README.en.md)**

一个基于 Java Swing 的桌面工具：使用统一变量系统填充文本或 Word 模板，并支持预览、复制和安全导出结果。

## 功能特性

- **左右分栏界面** → 左侧集中显示模板编辑与生成结果，右侧集中显示日期和统一变量输入；两组分隔条均可拖动并自动记忆位置
- **统一变量输入** → `{{变量名}}` 是推荐格式，每个变量可选择“数值 / 短字符串 / 多行文本”；数值留空按 0
- **旧语法迁移** → 读取到 `[[变量]]` 时可备份并一键转换为 `{{变量}}`
- **紧凑多行编辑** → 多行变量在主界面显示单行预览，通过“展开…”弹窗编辑完整内容
- **会话草稿保护** → 数值、短字符串和多行文本在当前模板编辑会话内分别保留；切换模板或退出后只长期保存当前类型和值
- **可调界面字号** → 默认“较大”，可选择跟随系统/较大/大/特大；基于 Windows 与 JDK 的 DPI 字体继续缩放，不重复计算显示 DPI
- **表达式数值锁定** → 以 `=` 开头表示算术表达式，如 `{{=变量1/变量2}}`；纯数字或特殊名称使用 `[变量名]` 显式引用，如 `{{=[1]*[2]}}`；支持 `+ - * / **` 和括号，结果保留两位小数
- **日历基准日期** → 所有内置日期变量均以日历选中的日期为基准；每次启动默认同步系统当天日期，也可手动输入 `yyyy-MM-dd` 或打开弹出日历选择日期
- **完整日期推导** → 支持昨日/今日/明日、上月/本月/下月、上年/本年/下年及本月月首/月末，跨月、跨年和闰年均自动处理
- **独立配置记忆** → 应用状态保存到 `config.json`，每个模板的变量值和类型分别保存到 `Config/模板名.json`
- **旧配置安全迁移** → 首次升级时只读迁移 `last_values.json`，迁移后不再修改或删除旧文件；配置采用临时文件与原子替换写入
- **结果状态保护** → 修改模板、变量类型、变量值或日期后立即废弃旧结果，禁止误复制或误保存
- **错误定位与可访问性** → 数值和日期错误实时显示文字/符号反馈，可用“定位错误”或 `F4` 循环聚焦；支持 `F1` 帮助、`Ctrl+Enter` 生成和 `Ctrl+S` 保存模板
- **非模态帮助窗口** → 提供语法说明、全部日期变量和随模板实时刷新的当前变量清单，打开后仍可继续操作主界面
- **多模板管理** → 模板文件任意命名存放在 `Templates/` 文件夹内，可「选择模板文件…」切换、「新建模板」、修改后「保存模板」写回对应文件，并记住上次使用的模板，下次启动自动恢复
- **模板即时修改** → 可在界面中直接编辑并保存，或点「打开文件夹」用外部编辑器修改
- **Word 模板支持** → 可直接选择 `.docx` 文件作为模板，替换正文、表格、页眉/页脚、脚注/尾注、批注和文本框中的变量，并保留原有文字与段落格式

## 快速开始

**环境要求**：Windows + JDK 17 或更高版本。

**运行**：

1. 双击 `launcher.bat`
2. 命令行执行 `java -jar TemplateTool.jar`

**修改模板**：模板是 `Templates/` 文件夹内的纯文本文件。点击顶栏「选择模板文件…」选择要用的模板，在下方编辑区修改后点「保存模板」写回该文件；「新建模板」可创建新文件；「打开文件夹」可打开模板文件夹，直接管理模板文件。

**填写变量**：右侧每个变量只显示一次。普通变量可选择数值、短字符串或多行文本；表达式引用的变量固定为数值。多行文本通过“展开…”编辑，取消不会修改原内容。

**键盘操作**：`Ctrl+Enter` 生成结果，`Ctrl+S` 保存文本模板，`Ctrl+加号/减号` 调整界面字号，`Ctrl+0` 跟随系统，`F1` 打开帮助，`F4` 循环定位输入错误；辅助对话框可用 `Esc` 关闭。

**使用 Word 模板**：在 Word 中把需要填写的部分写成 `{{变量名}}`。打开 `.docx` 后模板内容保持只读，“保存模板”禁用但仍可新建 `.txt` 模板；生成后的 Word 结果通过“保存结果到文件”导出。

## 变量语法

### 普通变量

使用双花括号声明变量：

```text
{{变量名}}
```

变量名是花括号中的完整内容，前后空白会被忽略。因此纯数字也可以作为普通变量名：

```text
客户：{{客户名称}}
第一项：{{1}}
备注：{{备注}}
```

每个普通变量可以在界面中选择以下类型：

- **数值**：接受普通十进制、小数和科学计数法；留空按 `0` 处理。
- **短字符串**：按原内容替换，适合单行文字。
- **多行文本**：保留换行，适合备注或长文本。

同名变量在模板中出现多次时只需填写一次。

### 算术表达式

花括号内容以 `=` 开头时表示算术表达式：

```text
{{=数量*单价}}
```

表达式支持 `+`、`-`、`*`、`/`、`**`（乘方）和括号，结果固定保留两位小数。表达式引用的变量会自动锁定为数值类型，留空仍按 `0` 处理。

表达式中有两种变量引用方式：

| 写法 | 用途 | 示例 |
| --- | --- | --- |
| 裸变量名 | 名称以文字开头，后面可包含文字、数字或下划线 | `{{=数量*单价}}` |
| `[变量名]` | 纯数字名称、带空格或带特殊字符的名称；也可显式引用普通名称 | `{{=[1]*[2]}}` |

数字变量和数字常量必须明确区分：

```text
{{=1*2}}          数字常量 1 × 2，结果为 2.00
{{=[1]*[2]}}      变量“1” × 变量“2”
{{=数量*2}}       变量“数量” × 数字常量 2
{{=[销售 数量]*[单价-折扣]}}
```

数字常量支持 `5`、`3.5`、`.5`、`2e3`、`1.5E-2` 等形式。内置日期变量不能参与算术运算。

### 内置日期变量

所有日期变量均以界面选择的基准日期为准：

| 写法 | 含义 |
| --- | --- |
| `{{今日年}}` `{{今日年月}}` `{{今日年月日}}` | 基准日期 |
| `{{昨日年}}` `{{昨日年月}}` `{{昨日年月日}}` | 基准日期前一天 |
| `{{明日年}}` `{{明日年月}}` `{{明日年月日}}` | 基准日期后一天 |
| `{{本月年}}` `{{本月年月}}` | 基准月份 |
| `{{上月年}}` `{{上月年月}}` | 上一个月 |
| `{{下月年}}` `{{下月年月}}` | 下一个月 |
| `{{上年}}` `{{本年}}` `{{下年}}` | 相对基准日期的年份 |
| `{{本月月首}}` `{{本月月末}}` | 基准月份第一天或最后一天 |

旧版 `[[变量]]` 写法已经弃用。读取旧模板时软件会提供一次性转换，未转换的旧占位符保持原样且不参与填充。

## 构建

双击 `build.bat`，或在命令行执行：

```bat
build.bat
```

构建需要 JDK（含 `javac` 和 `jar`）；构建脚本会先运行回归测试，成功后生成 `TemplateTool.jar`。
